# Dr. Audrey Project

Static website for Dr. Audrey — a small brochure site containing information, books, events, reviews, and contact details.

Repository: https://github.com/FaisalRahmanGit/dr-audrey-project

## Overview

This project is a lightweight static website made of HTML, CSS, and JavaScript. It contains several pages showcasing Dr. Audrey's work, books, events, newsletter signup, and contact information.

## Project Structure

- `index.html` — Home page
- `about.html`, `blog.html`, `contact.html`, `events.html`, `newsletter.html`, and other content pages
- `view_book1.html` — `view_book4.html` — Book pages
- `assets/` — Static assets
  - `css/style.css` — Styles
  - `js/script.js` — Client scripts
  - `images/` — Images and media
  - `fonts/` — Custom fonts
