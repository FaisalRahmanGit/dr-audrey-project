# Dr. Audrey Project

The **Dr. Audrey Project** is a multi-page static website created as a frontend design and development exercise. It simulates a professional brochure-style site for an author, showcasing books, events, blog content, reviews, and contact information.

This project focuses on clean layout structure, responsive navigation, and organizing content across multiple pages using modern frontend practices.

---

##  Project Overview

The goal of this project was to practice building a **real-world content-heavy static website** similar to author, consultant, or personal brand sites. It demonstrates how to structure pages, manage navigation, and present large amounts of information in a clear and user-friendly way.

---

##  How It Works

- Multi-page website with dedicated sections for:
  - Home
  - About
  - Books & individual book detail pages
  - Blog
  - Events
  - Newsletter signup
  - Contact information
- Responsive navigation with separate desktop and mobile menus
- Reusable layouts and components across pages
- Static content rendered using HTML and styled with CSS and Bootstrap
- JavaScript used for basic UI interactions and responsiveness

---

##  Key Features

- Multi-page static website architecture
- Responsive layout using Bootstrap 4
- Book showcase and detail pages
- Blog and event listings
- Newsletter and contact sections
- Clean typography and media integration
- Fully static (no backend or database)

---

##  Tech Stack

- **HTML5** – Page structure and content
- **CSS3** – Custom styling
- **Bootstrap 4** – Responsive layout and grid system
- **JavaScript (Vanilla)** – UI behavior
- **Font Awesome** – Icons and visual elements
